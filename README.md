# WeChat-auto-listener-reply

微信自动监听与回复（主页监听 → 跳转会话回复 → 返回主页继续监听）。

## 功能

- 持续在主页监听新消息（群聊与个人聊天都可命中关键词）。
- 命中关键词后自动执行流程：
  1. 跳转到对应消息会话。
  2. 发送自动回复。
  3. 返回主页继续监听。

## 使用步骤

1. 安装依赖（示例）：

```bash
pip install wxauto4
```

2. 编辑 `main.py` 顶部配置：

- `KEYWORDS`: 关键词列表。
- `AUTO_REPLY_TEXT`: 自动回复内容。
- `POLL_INTERVAL`: 监听轮询间隔（秒）。
- `ALWAYS_BACK_HOME`: 是否始终回主页监听（默认 `True`）。

3. 运行：

```bash
python main.py
```

## 说明

- 脚本会尽量兼容 `wxauto4` 不同版本的方法命名（跳转主页/会话/发送消息）。
- 如果无法识别会话名，会输出日志并跳过该条消息。
- 自动回复失败或单条处理失败不会中断监听循环。
